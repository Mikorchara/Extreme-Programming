# 通讯录

FZU–MU 软件工程「极限编程」作业。通讯录支持添加、查看、编辑、删除、搜索和收藏联系人，以及 Excel 导入导出。每位联系人可保存多条同类或不同类的联系方式。联系人保存在当前浏览器的 `localStorage` 中。[作业原帖](https://bbs.csdn.net/topics/620593436)

## 本地运行

在仓库根目录运行以下命令。项目使用原生 HTML、CSS 和 JavaScript，可直接由本地静态服务器提供页面。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 [本地通讯录](http://127.0.0.1:8000/)。

## 联系方式

- 姓名必填。电话、邮箱、社交账号和地址均可按需添加，同一类型可重复添加。
- 在联系人列表中选择联系人，左侧显示只读详情。需要修改信息时，选择「编辑」。
- 切换联系方式类型会清空该行原有的输入。
- 新增或修改的电话号码只允许输入 `0`–`9`，填写时需有 3–15 位。前导零会保留。国家或地区可以单独选择，也可以留空。
- 在联系人卡片上选择「删除」并确认，即可移除该联系人。

## Excel 导入导出

「导出 Excel」包含所有联系人，包括被当前搜索或筛选隐藏的联系人。通讯录为空时，导出的 `.xlsx` 只有表头，可直接用作模板。「导入 Excel」读取第一个工作表并追加联系人，文件有格式错误时会整体拒绝导入。表格在当前浏览器中处理。

首行填写表头，每位联系人占一行。姓名必填，收藏填「是」或「否」。同类联系方式从 1 开始编号。每条电话有对应的地区列，填写地区代码，例如 `CN`、`GB`、`IE`，也可以留空。在 Excel 中将电话号码列设为文本，以保留前导零。

| 姓名 | 收藏 | 电话 1 | 电话地区 1 | 电话 2 | 电话地区 2 | 邮箱 1 | 社交账号 1 | 地址 1 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 演示联系人 | 是 | 00012345678 | CN | 00012345679 | IE | demo@example.com | demo-account | 演示地址 |

## 本地验收

1. 新建 `演示联系人`，在电话框内尝试输入 `abc-123`，确认字母和符号无法留在输入框。填入 `00012345678` 后将类型切换为邮箱，确认该行输入框清空，再填入 `demo@example.com`。
2. 参照上表补填两条电话及其地区，保存并收藏联系人。在收藏列表中搜索 `demo@example.com`，再点击「导出 Excel」。打开文件，检查该联系人占一行且两个号码的前导零都保留。
3. 点击演示联系人的「删除」，先取消并确认联系人仍在，再确认删除并刷新页面。导入导出的 `.xlsx`，验证演示联系人重新出现，收藏状态、两条电话及其地区和邮箱均已恢复。
4. 修改测试文件，把一条电话号码改为 `abc` 后再导入。确认页面提示错误，联系人数量保持不变。

## 文件

| 文件 | 职责 |
| --- | --- |
| `index.html` | 联系人表单、搜索框和列表结构 |
| `styles.css` | 页面布局、响应式样式和控件状态 |
| `app.js` | 联系人存储、表单编辑、收藏、删除和列表更新 |
| `phone.js` | 电话地区选项和号码校验 |
| `excel.js` | 联系人数据与 Excel 工作表之间的转换 |
