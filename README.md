# 通讯录

FZU–MU 软件工程「极限编程」作业。当前版本支持添加、查看和搜索联系人，联系人数据通过浏览器的 `localStorage` 保存。[作业原帖](https://bbs.csdn.net/topics/620593436)

## 本地运行

在仓库根目录运行以下命令。项目使用原生 HTML、CSS 和 JavaScript，可直接由本地静态服务器提供页面。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 [本地通讯录](http://127.0.0.1:8000/)。

## 第一版验收

1. 在「新增联系人」中填写 `演示联系人`、`000-0000-0000` 和 `demo@example.com`，点击「添加联系人」，确认列表显示这条演示记录。
2. 搜索 `demo@example.com`，确认列表能找到这条记录。清空搜索框后应恢复完整列表。
3. 刷新页面，确认演示记录仍然存在。电话和邮箱均可留空，可以另用一条仅有姓名的记录验证。
